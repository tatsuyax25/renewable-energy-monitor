# 🌱 Renewable Energy Monitor

A real-time renewable energy monitoring dashboard that tracks solar production, energy consumption, carbon footprint, and cost savings.

## ✨ Features

- **Real-time monitoring** - Live solar production and consumption data
- **Carbon footprint tracking** - Calculate CO₂ savings from renewable energy
- **Cost analytics** - Track monetary savings and efficiency metrics
- **Interactive charts** - Monthly overview and weekly analytics
- **Responsive design** - Works on desktop, tablet, and mobile
- **Professional UI** - Modern gradient design with animated indicators

## 🚀 Live Demo

[View Live Application](https://renewableenergymonitordashboard.onrender.com)

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3, JavaScript
- **Charts**: Chart.js
- **Deployment**: Render
- **Styling**: CSS Grid, Flexbox, CSS Animations

## 📊 API Endpoints

- `GET /api/energy-data` - Monthly energy consumption and production
- `GET /api/real-time` - Live energy metrics and savings
- `GET /api/analytics` - Weekly performance analytics

## 🏃‍♂️ Quick Start

### Prerequisites
- Python 3.7+
- pip

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/tatsuyax25/renewable-energy-monitor
   cd renewable-energy-monitor
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   ./run.sh
   # or
   cd backend && python app.py
   ```

4. **Open your browser**
   ```
   http://localhost:5000
   ```
